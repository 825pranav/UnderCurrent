# UnderCurrent — Dataset Evaluation

Replay real fault datasets through the pipeline and measure detection rate,
false positive rate, and response latency against known ground truth.

---

## Quickstart — Synthetic (no download needed)

```bash
cd ~/UnderCurrent/stateless

# Step 1: replay synthetic faults through the pipeline
python3 testing/replay.py --dataset synthetic --faults 30

# Step 2: evaluate
python3 testing/evaluate.py
```

---

## Using RCAEval (recommended)

### Download
```bash
pip install gdown
python3 -c "
import gdown
gdown.download_folder('https://drive.google.com/drive/folders/1F8EoTjBsQFMvNFbDKQ2kFGBDqbKBkCCO', output='rcaeval_data')
"
```
Or manually from: `github.com/phamquiluan/RCAEval` → Releases → download dataset zip.

### Run
```bash
python3 testing/replay.py --dataset rcaeval --data-dir ./rcaeval_data
python3 testing/evaluate.py
```

## Using Alibaba Cluster Trace

### Download
```bash
# From: github.com/alibaba/clusterdata
wget https://github.com/alibaba/clusterdata/raw/master/cluster-trace-container-v2022/container_event.csv
```

### Run
```bash
python3 testing/replay.py --dataset alibaba --data-file ./container_event.csv
python3 testing/evaluate.py
```

## What the metrics mean

| Metric | What it measures | Target |
|---|---|---|
| **Detection Rate** | % of injected faults that triggered a real action | As high as possible |
| **False Positive Rate** | % of actions taken when no fault existed | As low as possible |
| **Avg Latency** | Seconds between fault injection and system response | < reconcile interval (5s) |
| **P95 Latency** | 95th percentile latency | < 10s |
| **Shadow Agreement** | % of cycles where real and shadow paths agreed | Should be ~100% |

---

## Files

| File | Role |
|---|---|
| `dataset_loader.py` | Loads RCAEval / Alibaba / synthetic data, maps to UnderCurrent schema |
| `replay.py` | Feeds events through the pipeline, saves ground_truth.json |
| `evaluate.py` | Computes all metrics, prints report, saves evaluation_report.json |
| `ground_truth.json` | Auto-generated by replay.py |
| `evaluation_report.json` | Auto-generated by evaluate.py |
